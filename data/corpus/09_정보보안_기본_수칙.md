# 정보보안 기본 수칙

## 계정 및 비밀번호 관리 정책
넥사테크의 모든 자산과 고객 데이터를 보호하기 위해 강력한 인증 정책을 적용합니다.
- **비밀번호 복잡도**: 모든 사내 시스템 비밀번호는 최소 12자리 이상, 영문 대소문자/숫자/특수문자를 각 1자 이상 포함해야 합니다.
- **패스워드 매니저 사용 의무**: 모든 임직원은 사내 공식 배포된 '1Password Business' 볼트를 의무적으로 사용해야 하며, 브라우저 자동 저장이나 포스트잇, 개인 메모장 기록은 엄격히 금지됩니다.
- **다중 요소 인증(2FA/MFA)**: 사내 이메일, Slack, GitHub, VPN, 클라우드 콘솔 등 모든 시스템은 2단계 인증이 필수이며, SMS 인증 대신 OTP 앱 또는 물리 보안키 사용을 원칙으로 합니다.

## 개인 기기(BYOD) 및 단말 보안
- **지급 단말기 사용 원칙**: 사내 모든 업무 및 소스코드 작성, 고객사 데이터 조회는 회사에서 공식 지급한 보안 단말기에서만 수행해야 합니다.
- **개인 PC 업무 사용 제한**: 개인 소유 노트북, 태블릿, 스마트폰에 회사 기밀 파일이나 소스코드를 다운로드하거나 저장하는 행위는 보안 규정 위반에 해당합니다.
- **자리 비움 시 화면 잠금**: 잠시 자리를 비울 때도 반드시 화면을 잠금 상태(macOS 단축키: `Ctrl + Cmd + Q`)로 전환해야 합니다. 사내 정책에 따라 10분 이상 미조작 시 화면 보호기 및 암호 잠금이 자동 활성화됩니다.

## 데이터 보호 및 외부 반출 금지
- **고객사 데이터 및 소스코드 보호**: 고객사로부터 수령한 원본 데이터, 사내 LLM 학습 데이터셋, 지식 베이스 문서는 인가된 사내 인프라 내에서만 처리되어야 합니다.
- **공개 클라우드 업로드 금지**: 회사의 사전 승인 없이 개인 Google Drive, Dropbox, Notion, 외장 USB 메모리 등으로 데이터를 반출하거나 Public GitHub 저장소/Gist에 업로드하는 행위는 엄격히 금지됩니다.
- **사내 전용 Git 저장소 준수**: 모든 개발 산출물은 사내 GitHub Enterprise 조직 내 지정된 프라이빗 레포지토리에만 커밋되어야 합니다.

## 보안 사고 신고 및 대응 절차
- **즉각적인 신고 의무**: 피싱 의심 이메일 수신, 단말기 분실, 계정 탈취 의심, API 키 외부 유출 징후 발견 시 지체 없이 정보보안팀에 신고해야 합니다.
- **신고 채널**:
  - Slack 긴급 채널: `#security-incident` (24시간 온콜 모니터링)
  - 이메일: `security@nexatech.ai`
  - 긴급 유선 핫라인: 사내 내선 02-1234-5678 (비상 보안 관제 데스크)
- **면책 및 보고 문화**: 실수로 발생한 유출 사고라도 최초 인지 후 1시간 이내에 자진 신고한 경우 비고의성 감경 규정이 적용됩니다.
