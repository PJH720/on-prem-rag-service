# 개발 환경 및 배포 규정

## 필수 개발 도구 및 로컬 스택 구동
- **런타임 사양**: macOS 14+ 또는 Ubuntu 22.04+, Node.js 22 LTS, pnpm 10+, Python 3.12 (`uv`), Docker Desktop.
- **로컬 인프라 구동 (Docker Compose)**:
  ```bash
  git clone git@github.com:PJH720/on-prem-rag-service.git
  cd on-prem-rag-service
  docker compose up -d    # PostgreSQL 16 (pgvector), Redis 7, MinIO 기동
  pnpm install && pnpm db:migrate
  ```

## 코드 리뷰 및 PR 승인 규칙
- **브랜치 전략**: Trunk-Based Development (`feat/ENG-{이슈번호}-{기능명}`).
- **PR 승인 요건**: 최소 1인 이상의 동료 엔지니어 Approve 및 CI 파이프라인(린트/테스트/보안스캔) 100% 통과 필수.

## 프로덕션 배포 및 배포 동결 시간 (Deployment Freeze)
- **정기 배포 시간**: 화요일 ~ 목요일 10:00 ~ 16:00.
- **배포 동결(Freeze) 정책**: 금요일 14:00 이후 및 공휴일 전날 프로덕션 신규 배포를 전면 금지합니다.
