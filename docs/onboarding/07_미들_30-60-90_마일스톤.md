# 온보딩 미들 30/60/90 마일스톤 (데모)

| 시점 | 목표 | 검증 방법 |
|------|------|-----------|
| D+7 | 개발환경 셋업 완요, 스모크 테스트 통과 | PR 머지 |
| D+30 | 첫 프로덕션 기여 (도크 또는 소규모 수정 포함) | 팀 레뷰 |
| D+60 | 서브태크 단위로 스코프 → 구현 → 배포 혼자 완수 | 릴리즈 노트 기제 |
| D+90 | 1On1 기반 정식 피드백, 정고착 임계 전 OKR 합의 | 피플팀 면담 |

## 멘토링 편성

- **배디 (Buddy)**: 입사 후 1간, 사소 질문 창구 — 하수진 (dev-infra)
- **멘토 (Mentor)**: 기술 그로스 담당, 격주 30분 1On1 — 김하늘 (엔지니어링팀장)
- **BF (Business Friend)**: 피플팀 접촉, 30/60/90 면담

## 정고착 체크항목 (정량 기준 예시)

1. 코드 기여 PR 5개 이상 머지
2. 온콜 섀도우 2회 이상 참관
3. 인시던트 레뷰 참여 1회 이상
4. 분기 OKR KR 진척도 평균 70% 이상
