# 개발환경 셋업 가이드 (데모)

## 요구사항

- macOS 14+ 또는 Ubuntu 22.04+
- Homebrew, `uv` (파이썬), `pnpm` 9+, `docker` 26+
- 사내 VPN 접속 가능 상태 (VPN 없으면 아래 레지스트리 접근 불가)

## 1. 사내 패키지 레지스트리 접속

```bash
# npm 스코프 @newbluem 은 사내 레지스트리 사용
npm config set @newbluem:registry https://npm.internal.newbluem.tech/
npm login   # 사내 GitLab 어카운트로 토큰 발급

# 파이썬은 사내 PyPI 미러
export UV_INDEX_URL=https://pypi.internal.newbluem.tech/simple
```

## 2. 프로젝크 클론 & 설치

```bash
git clone git@git.internal.newbluem.tech:core/rag-service.git
cd rag-service
uv sync           # 백엔드 (파이썬 3.12)
pnpm install      # 프론트엔드
docker compose up -d   # postgre+pgv, redi, minio
```

## 3. 환격 변수

`.env.example`을 복서해서 사용하세요. 실제 값은 사내 어카운트 관리자 1Password Vault `dev-onboarding`에서 확인 (IT팀에 접근 신청).

| 키 | 설명 |
|----|------|
| `PG_PASSWORD` | 로컬 Postgres 암호 (데모: `demo-local-only`) |
| `OPENAI_API_KEY` | 데모용 더미 키, 사내 게이트웨이 경유 시 불필요 |
| `EMBEDDING_MODEL` | 기본값 `bge-m3-large` (사내 호스팅) |

## 4. 스모크 테스트 (온보딩 과제)

```bash
make smoke   # 헬스체크 + 인덱싱 파이프라인 E2E
```

통과하면 `logs/smoke-<date>.log`를 온보딩 PR에 첨부와해서 팀장 레뷰를 받으세요.

## 트러블슈팅

| 증샹 | 대법 |
|------|------|
| `pnpm install` 401 | 사내 레지스트리 토큰 만료 — `npm login` 재시행 |
| Embedding timed out | VPN 연결 상태 확인 후 `make restart-embedding` |
| Docker 빌드 실패 | `docker system prune` 후 재시도 |
