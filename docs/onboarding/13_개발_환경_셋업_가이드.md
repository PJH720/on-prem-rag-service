# 개발 환경 셋업 가이드

## 필수 개발 도구 및 런타임 설치
넥사테크 개발본부의 표준 개발 환경 구성을 위한 단계별 가이드입니다.
- **운영체제 권장 사양**: macOS Sonoma 14+ 또는 Ubuntu Linux 22.04 LTS 이상.
- **패키지 매니저 및 런타임**:
  ```bash
  # 1. Homebrew 설치 (macOS)
  /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  
  # 2. Node.js 22 LTS 및 pnpm 설치
  brew install node@22 pnpm
  pnpm setup
  
  # 3. Python 3.12 툴체인 (uv 초고속 패키지 관리자)
  curl -LsSf https://astral.sh/uv/install.sh | sh
  
  # 4. Docker Desktop 및 CLI 도구
  brew install --cask docker
  brew install gh jq ripgrep
  ```
- **Git 글로벌 환경설정**:
  ```bash
  git config --global user.name "홍길동"
  git config --global user.email "gildong.hong@nexatech.ai"
  ```

## 사내 패키지 저장소 및 Git 인증
사내 전용 라이브러리 및 저장소 접근을 위해 인증 토큰을 등록합니다.
- **사내 npm 레지스트리 설정**:
  ```bash
  # @nexatech 스코프 패키지는 사내 레지스트리 연결
  npm config set @nexatech:registry https://npm.nexatech.internal/
  npm login --registry=https://npm.nexatech.internal/
  ```
- **GitHub SSH 키 등록**:
  ```bash
  ssh-keygen -t ed25519 -C "gildong.hong@nexatech.ai"
  gh ssh-key add ~/.ssh/id_ed25519.pub --title "Work MacBook Pro"
  ```

## 로컬 개발 스택 구동 (Docker Compose)
온프레미스 RAG 서비스 및 코어 API 개발을 위한 로컬 데이터베이스와 인프라 스택을 구동합니다.
1. **저장소 클론**:
   ```bash
   git clone git@github.com:PJH720/on-prem-rag-service.git
   cd on-prem-rag-service
   ```
2. **환경 변수 파일 복사**:
   ```bash
   cp .env.example .env.local
   # 사내 1Password 'Engineering-Dev' 볼트에서 개발용 API 키 및 접속 정보 확인 후 입력
   ```
3. **로컬 데이터베이스 컨테이너 구동**:
   ```bash
   docker compose up -d
   # PostgreSQL 16 (pgvector 활성화), Redis 7 (캐싱), MinIO (로컬 객체 스토리지) 구동
   ```
4. **의존성 설치 및 DB 마이그레이션**:
   ```bash
   pnpm install
   pnpm db:migrate
   ```

## 스모크 테스트 및 온보딩 과제 검증
로컬 환경 셋업이 정상적으로 완료되었는지 검증하기 위해 스모크 테스트를 실행합니다.
- **테스트 실행 명령어**:
  ```bash
  pnpm test:smoke
  ```
- **검증 항목**:
  1. PostgreSQL 벡터 익스텐션 정상 연결 및 BM25 인덱스 생성 여부
  2. 로컬 온프레미스 LLM 게이트웨이 엔드포인트(`http://spark-f5e2.tail0bfda4.ts.net:8000/v1`) 헬스체크 통과
  3. RAG 쿼리 파이프라인 종단간(E2E) 호출 및 한국어 답변 생성 확인
- **온보딩 과제 제출**: 테스트 통과 로그를 캡처하여 GitHub 온보딩 전용 브랜치(`feat/onboarding-setup`)에 첫 PR을 생성하고 팀장 리뷰를 요청하세요.
