# 회사소개

## 뉴블럼테크는 어떤 회사인가

뉴블럼테크(NewBlueM Tech)는 2019년에 설립된 **AI 인프라 / 데이터 플랫폼 전문 기업**입니다.
기업 고객사에 검색증강생성(RAG) 파이프라인, 사내 지식관리 시스템, LLM 운영 플랫폼을 구축해 줍니다.

- **미션**: "모든 조직의 지식이 즉시 사용가능한 형태로 바뀌도록 한다."
- **규모**: 임직 84명 (데모 데이터 기준)
- **위치**: 판교교 테크밸리 타워 8–10층

## 연혁

| 연도 | 이벤트 |
|------|--------|
| 2019 | 회사 설립, 검색 엔진 컨설팅팅 시작 |
| 2021 | 첫 RAG 파이프라인 구축 사업 수주 |
| 2023 | 시리즈 A 투자 유취 (200억) |
| 2024 | 사내 LLM 게이트웨이 'Bluemgate' 출시 |
| 2026 | 고객사 40개사 돌파 |

## 일하는 방식

- **비동근무**: 주 3일 오피 출근, 주 2일 재택 (팀별 상이)
- **소통**: 이진행에서 이슘용, 긴급은 톡신
- **회이 문화**: 주간 팀 스탠업 30분, 격주 레트로 60분
- **평가는 분기 1회**, OKR 기반
