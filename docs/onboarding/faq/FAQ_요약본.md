# 온보딩 FAQ

## 온보딩 일정과 절차

- 입사 첫날 10시 피플팀에서 온보딩 팻킷을 배포합니다.
- 첫날은 보안 서약, 어카운트 개설, IT장비 수령을 진행합니다.
- 첫날 오후 배디와 커피타임을 합니다.
- 2주차까지 온보딩과제를 제출합니다.
- 1개월, 3개월, 6개월 면담을 진행합니다.
