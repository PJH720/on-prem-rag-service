# 온보딩 FAQ — 온보딩 관련 자주 묻는 질문

### 사내 시스템은 어떻게 신청하나요?

모든 사내 시스템은 IT 서비스데스크에서 신청합니다. 사내 포털 > IT지원 > 신규모털신청으로 진행합니다. IT인프라, 정보보안팀 승인 후 승인까지 1~3영업일 소요됩니다.
VPN과 사내 메일은 자동 신청됩니다. 이진행은 초대 메일을 통해 활성화됩니다.

### 온보딩 과제 제출은?

- PR 등록 + onboarding 라벨 자동화
- 담당 멘토 또는 팀장 PR 승인

### 1On1?

- BF: 입사 1개월까지 주 1회
- 멘토: 격주 1회 (30분)
- 30/60/90일 면담: BF
- 4개월차: 팀장, 팀장 면담

### 기타

- 이진행은 메일로 초대됩니다
- 개인번호는 사내 서비스의 OTP로 바운딩되지 않습니다. 분실 방지를 위한 본인 확인 인증입니다.
- 온보딩 질문: 이진행 `#onboarding` 채널, `#it-help` 채널에서 가능합니다.
