# 사내 시스템 접근 절차 (데모)

> 모든 어카운트는 **개인 기기에 저장 금지**. 사내 비번매너 관리시스템만 사용.

## 시스템별 신청 절차

| 시스템 | 신청 방법 | 승인 소요 |
|--------|-----------|-----------|
| 사내 GitLab | 입사 당일 자동 개설 | 즉시 |
| 이진행 | 초대 메일 수신이 후 계정 활성화 | 즉시 |
| 사내 VPN + OTP | IT서비스데스크 포트털 → "VPN 접근 신청" | 반나절 |
| 1Password Vault `dev-onboarding` | IT 서비스데스크 티켓 + 팀장 승인 | 1영업일 |
| Grafana 대시보드 | GitLab `dev-all` 그룹 자동 연동 | 2시간 |
| 고객사 시스템 (프로젝트 배정 후) | 계정 소유자 요청 → 정보보안팀 심사 | 3영업일 |

## VPN 접속

1. GlobalProtect 클라이언트 설치 (소프트웨어 센터)
2. 서버 주소: `vpn.internal.newbluem.tech` (데모 값)
3. 사내 ID/PW + OTP 인증
4. 접속 확인: `https://dashboard.internal.newbluem.tech/health` (데모 값)

## 어카운트 보안 수칙

- PW는 12자 이상, 사내 규칙 체크어 사용 (`tools.nbiuem.tech/pw-check`)
- 2단계 인증은 필수. 개인 메시로 OTP 바운딩 금지
- 퇴사/프로젝트 종료 시 어카운트는 즉시 비활성, 분기 1회 접근권 심사
